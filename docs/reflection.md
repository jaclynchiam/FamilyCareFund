# Personal Reflection

The experience of building this project was new to me because I had never built a complete and fully working desktop application before. Overall, it was a valuable and meaningful experience because I was able to apply the Object-Oriented Programming (OOP) concepts that I learned in lectures to a real application.

When I first started the project, the first thing I had to decide was the topic. I chose to develop a subsidy eligibility calculator and named it **FamilyCareFund**. My main idea was to help low-income households check whether they may be eligible for government subsidies and make the process of seeking financial assistance easier. I chose this idea because I believe that government subsidies can be important for low-income families, but some families may not know what they are eligible for or how to begin the application process.

While designing the system, I realised that simply creating an eligibility calculator would not fully address the problem I wanted to solve. Some low-income families may not have enough knowledge or ability to complete complicated subsidy application procedures. Therefore, I decided to expand FamilyCareFund by adding an **NGO assistance feature**. If a user is eligible for a subsidy but needs help with the application process, they can request assistance from the organisation through the system. In this way, FamilyCareFund is not only a calculator but also provides a way for users to receive further support. I felt that this design was more meaningful because it could potentially help users who would otherwise struggle to apply for assistance on their own, while also contributing to SDG 1 — No Poverty.

One of the biggest challenges during the project was actually the **system design rather than the programming itself**. Although AI tools could help me with programming problems, I felt that the overall design of the system should come mainly from my own ideas. I spent around four to five days thinking about how the system should work, what types of subsidies should be provided, what information should be collected from users, and what conditions should determine their eligibility. Only after I had a clearer idea of the system did I start designing the UML diagram and implementing the code.

Adding NGO assistance also made the system more complex because I needed to design an **admin flow**. Instead of only having a simple user login and eligibility calculation process, I created an admin function where administrators can log in, view user information and identify users who require assistance. Because of this feature, I also had to think more carefully about the information collected from users. The system needs more detailed household information, such as the need to collect information for every member in the household, their financial situation and additional information,  so that the organisation can better understand a user's circumstances and provide more appropriate assistance.

Although these design decisions made the project more complicated and required more implementation time, I believe they were worthwhile. Through this project, I learned that developing a good software system is not only about writing code. It also requires having a clear idea of the problem, designing a suitable solution and making decisions about how different parts of the system should work together.

I also learned how to use AI tools more effectively during development. I mainly used **ChatGPT** for discussing system design and understanding programming concepts, while I found **Claude** useful for assisting with code implementation. However, I still had to understand, review and adapt the generated code to fit my own design.

Overall, this project improved my programming, system design and problem-solving skills. Most importantly, I learned how to turn my own idea into a working application and how OOP concepts can be applied to build a larger system that addresses a real-world problem. If I had more time, I would further improve the validation, user interface and NGO assistance features to make FamilyCareFund more practical and useful.
