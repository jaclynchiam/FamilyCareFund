# AI Integration Reflection
AI played an important role in helping me develop FamilyCareFund throughout this project. Since this project is under Tier C, I used AI tools regularly during the development process. The two main AI tools I used were ChatGPT and Claude. However, I did not rely on AI to decide the complete design of my system. I mainly used AI to help me turn my ideas into working code, understand concepts and solve problems that I encountered during development.

At the beginning of this project, I first used AI to help me understand what a subsidy eligibility calculator actually is and how it works. I also did my own research on Google to understand more about this type of system.

In this project, the AI tools I used the most were ChatGPT and Claude. At the beginning, I used ChatGPT and Gemini to understand what a subsidy eligibility calculator is and how the system normally works. After I understood the basic idea, I started to design my own system flow, what features I wanted to have and how I wanted the system to work. After I had my own ideas, I put them into AI and asked it to help me organise how I could design the case classes and implement the system.

When I did this, I noticed that ChatGPT and Claude gave me quite different feedback. For example, when I said that I wanted to add NGO assistance, Claude initially suggested that I should not make the system too complicated. Since I had also pasted the assignment criteria to Claude, it pointed out that the assignment only required at least four features, so there was no need to add so many things. However, when I put the same idea into ChatGPT, the feedback was different. ChatGPT supported my idea more and helped me break down how I could actually implement the NGO assistance feature.

For designing the system, I found ChatGPT more useful. I gave ChatGPT my ideas about what classes I wanted and how I wanted the system to work, and then we discussed how to organise the classes, what methods I might need and what relationships the classes should have. I also used it to help me organise my UML design, including the classes and traits.

After finishing the system design, I started coding. At first, I used ChatGPT, but I found that there were quite a lot of errors in the code and some of the code could not run properly. Because of this, I changed to Claude for the coding part. I found that Claude's code was more accurate and could usually run properly. However, I also learned that I needed to give Claude very clear prompts. If I did not clearly tell it what I wanted, it normally would not add it by itself.

I also identified one of the problems when developing this application using AI. For example, in AI Log #Entry 11, the code could run normally, but when the user added a household member, the information that the user had already entered disappeared when returning to the previous scene. At that time, I had already reached Claude's usage limit, so I tried using Gemini to solve the problem. However, I spent a long time trying to solve it and still could not fix it. When I could use Claude again the next day, I explained the problem clearly and told it how I wanted the system to behave. Claude then gave me an updated solution that fixed the problem.

Overall, using AI in this project was a good experience. I did not completely depend on AI to design my system. The main idea of how FamilyCareFund should work, the features and the case class structure were mostly my own ideas. I mainly used AI to help me implement those ideas and solve problems during coding. I also did not simply copy the code from AI. Every time AI gave me code, I ran it myself and checked whether it worked and whether it actually matched what I wanted. When something was wrong, I gave AI my requirements again and asked it to change the code. Through this project, I learned that AI is useful for helping me turn my own ideas into a working system, but I still need to understand and check the code myself.
